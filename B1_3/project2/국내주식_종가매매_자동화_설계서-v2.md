# [프로젝트 2] Make(Integromat) 기반 국내주식 종가매매 자동화 설계 및 구현

## 1. 개요 및 목적
본 프로젝트는 **국내 증시 마감 데이터 및 수급 분석 데이터를 기반으로 종가매매 추천 종목 및 분석 리포트를 자동으로 추출·생성하여 텔레그램(Telegram)으로 전송하는 시스템**을 구축하는 것을 목표로 합니다.
기존의 수동 데이터 세팅 방식(`Set Variable`)을 향후 **오후 7시 지정 시각에 텔레그램 메세지를 수신하여 자동 실행하는 구조**로 고도화하는 변경사항을 반영하였습니다.

---

## 2. 자동화할 반복 업무 정의
* **반복 업무 명칭**: 매일 장 마감/저녁 시간대 국내주식 종가매매 대상 종목 분석 및 보고서 전송
* **기존 수행 방식**: 
  1. 매일 장 마감 후 시장 주요 지수 및 개별 종목 수급(기관/외국인/연기금) 데이터 수집.
  2. 주요 폭락주 및 연기금 매수 집중 종목 데이터 직접 필터링 및 텍스트 작성.
  3. 500일 일봉 패턴, 거래량, 상대가치 분석을 통한 종가매매 전략 수동 작성.
  4. 작성된 분석 내용을 매매 알림 채널(텔레그램)에 복사/붙여넣기 전송.
* **비효율성 및 페인 포인트**: 
  - 수동으로 시황 텍스트 데이터를 입력하거나 변수로 지정하는 방식은 유연성이 떨어짐.
  - 매일 동일한 구조의 수급/시황 데이터를 정리하고 메신저로 전송하는 단순 반복 노동 발생.
  - 감정적 판단 배제 및 데이터 기반의 자동화 파이프라인 구축 필요.

---

## 3. 자동화 도구 선정 및 선정 이유
* **선정 도구**: **Make (구 Integromat)**
* **선정 이유**:
  1. **노코드/로코드 기반 시각적 워크플로우 Builder**: 모듈 간 연결 구조가 직관적이어서 트리거 모듈 교체 및 고도화가 간편함.
  2. **AI Agent 및 LLM 연동 편의성**: `Make AI Agent` 모듈을 표준 지원하여 complex한 주식 시황 데이터 분석 및 전략 수립 프롬프트를 간편하게 실행 가능.
  3. **텔레그램(Telegram) 양방향 연동 지원**: 메시지 수신 트리거(`Watch Messages` / `Get Messages`)와 메시지 발송(`Send a Text Message / Reply`) 모듈이 충실히 지원됨.
  4. **스케줄링 기반 자동 운영**: 매일 지정된 시각(예: 오후 7:00)에 맞춰 자동으로 메시지를 수신·처리하는 스케줄러 기능 제공.

## 4. 워크플로우 설계 문서 (Workflow Architecture)

### 4.1 워크플로우 파이프라인 개요 (모듈 교체 반영)
기존의 수동 입력 변수 모듈(`util:SetVariable2`)을 **오후 7시 텔레그램 메시지 수신 모듈(`telegram:WatchMessages` / `telegram:GetMessages`)**로 교체하는 모듈 파이프라인 구조입니다.

```
[Module 1: Telegram Receiver]      [Module 2: AI Agent]               [Module 3: Telegram Sender]
┌───────────────────────────┐    ┌───────────────────────────┐      ┌───────────────────────────┐
│  telegram:WatchMessages   │    │  ai-local-agent:          │    │  telegram:                │
│  / GetMessages            │──> │  RunLocalAIAgent          │──> │  SendReplyMessage         │
│  (매일 19:00 메시지 수신) │    │  (종가매매 전략 분석/추천)│    │  (결과 텔레그램 전송)     │
└───────────────────────────┘    └───────────────────────────┘      └───────────────────────────┘
```

### 4.2 모듈별 상세 설계 specifications

| 모듈 구분 | 모듈명 | 역할 및 데이터 흐름 | 주요 설정 값 |
| :---: | :---: | :--- | :--- |
| **#1 (변경)** | `telegram:WatchMessages` 또는 `GetMessages` | 매일 **오후 7:00(19:00)**에 실행 스케줄링. 지정된 텔레그램 채널/대화방의 최신 마감 수급 메시지 텍스트(`{{1.text}}`)를 추출 | • **Schedule**: Everyday at 19:00<br>• **Limit**: 1<br>• **Filter/Source**: 지정된 시황 수신 채널 ID |
| **#2** | `ai-local-agent:RunLocalAIAgent` | 수신된 텔레그램 메시지 내용(`{{1.text}}`)을 입력값으로 전달받아 500일 일봉, 거래량, 수급 분석 기반 종가매매 리포트 생성 | • **Model**: `gpt-5-nano` (Medium Model)<br>• **System Prompt**: 추천종목 추출 및 종가매매 전략 수립 (500일 일봉, 거래량, 수급 분석 포함)<br>• **Input**: `{{1.text}}` |

## 7. 결론 및 향후 기대 효과
1. **완전 자동화 수집 체계 구축**: 기존에 수동으로 시황 데이터를 지정하던 방식에서 벗어나, 매일 오후 7시 텔레그램 메시지를 자동으로 감지하여 작동하는 Complete Automation 구현.
2. **시간적 유연성 확보**: 저녁 7시 정시 브리핑 형태로 자동 분석 보고서를 생성하여 수급 확정치 및 저녁 시장 반응까지 종합 고려 가능.
3. **유지보수성 향상**: 데이터 입력원(Source)과 데이터 수신원(Target)이 모두 텔레그램 파이프라인으로 통합되어 관리 편의성 극대화.
