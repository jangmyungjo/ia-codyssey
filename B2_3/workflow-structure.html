플랫폼별 생성 규칙

인스타그램 짧고 친근한 캡션 + 해시태그 10개
블로그 제목 + 소제목 2개 이상 + 본문 500자 이상
X 출처 링크 포함 · 가중 글자 수 280 이내
현재 구현은 세 플랫폼을 순차 생성합니다.
형식 검사 → 출처·숫자 검사 → AI 근거 대조 → 통과 또는 수정

이미지 이후 무인 저장 연결

앱 서버 → 이미지 도우미 → 전용 ChatGPT Chrome
이미지 회수 → 인증된 완료 콜백 → 서버 검증
R2 이미지 저장 + D1 상태 저장 → save 완료
이미지 작업 등록 후에는 앱 화면이 닫혀도 저장이 이어집니다.
