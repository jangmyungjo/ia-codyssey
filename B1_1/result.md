# 1. [산출물 1] LLM 모델 비교·선정 보고서

## 1.1 비교 목적 및 대상 모델

* **비교 목적:** 비정형 HTML 표 구조로 이루어진 금융 공시 문서에서 복잡한 조건부 수치(권면총액, 실제 취득가, 콜/풋옵션 분할, 소각/재매각 여부)를 환각 없이 추출하고, 이를 초보자 눈높이로 해설하는 데 가장 적합한 최적의 LLM을 선정한다.
* **사용 환경:** 각 모델 제공사 웹 인터페이스 (단일 채팅 세션, In-Context 프롬프트 주입 방식)
* **비교 대상 모델 3종:**

  1. Google Gemini 3.1 Pro
  2. Anthropic Claude Sonnet 4.6
  3. OpenAI GPT-5.4

## 1.2 테스트 동일 입력 데이터 및 프롬프트

### [테스트 대상 공시 원문 데이터]

* **기업명/공시명:** 에스티팜 / 전환사채(해외전환사채 포함) 발행후 만기전 사채 취득 (2026.08.11 공시)
* **핵심 팩트:**

  * 권면총액: 300억 원 / 실제 취득금액: 30,444,549,260원 (이자 포함)
  * 취득 사유 1: 295.5억 원 (발행회사 콜옵션 행사 → 추후 이사회 결정 미정)
  * 취득 사유 2: 4.5억 원 (사채권자 풋옵션 행사 → 한국예탁결제원 등록채권 말소/소각)
  * 취득 후 잔여 권면총액: 21,100,214,336원 (약 211억 원) / 주당 전환가액: 79,648원

### [동일 입력 테스트 프롬프트]

```text
[역할] 너는 주식 초보자에게 어려운 금융 공시를 알기 쉽게 설명해 주는 10년 차 금융 에디터다.
[입력] 첨부된 에스티팜 '전환사채(해외전환사채 포함) 발행후 만기전 사채 취득' 공시 HTML 텍스트를 분석해라.

[출력 요구조건]
1. [3줄 핵심 요약]: 공시의 핵심 팩트(회사명, 취득 금액/권면총액, 취득 사유)를 숫자를 포함해 3줄로 정리할 것.
2. [초보자 눈높이 해설]: '만기 전 사채 취득'이 무엇인지 일상적인 비유를 들어 2단락 이내로 쉽게 설명할 것.
3. [주주 관점 유불리 분석]: 공시 본문의 '취득 후 처리 방법(소각 vs 재매각/보유)'을 확인하여 기존 주주 입장에서 호재인지 악재인지 논리적 근거 3가지를 bullet으로 제시할 것. (단, 미정인 경우 단정하지 말 것)
4. [주의 사항]: 단정적인 주가 예측이나 매수/매도 권유는 절대 포함하지 말 것.
```

## 1.4 모델별 실행 결과 요약 및 상세 분석

### 1) Google Gemini 3.1 Pro (총점: 24.5 / 25) - 1위 선정

* **결과 요약:** 취득 총액(300억 원), 실제 지급액(304.4억 원), 콜옵션(295.5억 원, 미정), 풋옵션(4.5억 원, 소각)을 오차 없이 완벽히 분리 추출함.
* **강점:** 4.5억 원을 '파쇄기', 295.5억 원을 '금고 보관'으로 비유하여 주린이 맞춤형 페르소나를 가장 탁월하게 수행함. 100% 자기자금 상환에 따른 재무 건전성까지 유기적으로 도출함.
* **약점:** 3줄 요약 섹션에서 세부 불릿을 포함해 총 4줄로 서술되어 형식 준수도에서 0.5점 감점.

### 2) Anthropic Claude Sonnet 4.6 (총점: 14.5 / 25) - 3위

* **결과 요약:** 취득 후 잔여 사채액(211억 원)을 '이번 취득 규모'로 혼동하여 취득 금액 자체를 잘못 산출하는 중대한 수치 환각(Hallucination) 발생.
* **약점:** 수치 파싱 실패로 인해 295.5억 원(콜옵션)을 '소각', 4.5억 원(풋옵션)을 '재매각'으로 원문 팩트와 정반대로 해석하여 리스크 분석 전체가 왜곡됨. 3줄 요약 대신 임의의 표 서식을 생성함.

### 3) OpenAI GPT-5.4 (총점: 21.5 / 25) - 2위

* **결과 요약:** 취득 권면총액 300억, 실제 취득금 304.45억, 잔여 사채 211억을 정확히 구분함. 잔여 CB 211억의 오버행 잔존 리스크를 균형 있게 짚음.
* **약점:** 295.5억 원의 소각 여부에 대해 확신하지 못하고 HTML 인코딩 문제를 언급하는 등 메타 발언이 포함되어 에디터 페르소나 몰입도가 다소 저하됨.

>
> 2. **독보적인 눈높이 설명력:** 콜옵션과 풋옵션의 서로 다른 처리 방식을 '금고 보관'과 '파쇄기 말소'라는 직관적인 일상 비유로 전환하여 타겟 사용자의 이해도를 극대화했습니다.
>
> 3. **안전성 및 규격 준수:** 단정적 주가 예측을 지양하고 미정 상태인 물량의 리스크를 균형 있게 분석하였으며, 번역투 없는 자연스러운 비즈니스 한국어를 구사하여 최종 자동화 모델로 선정했습니다.

# 2. [산출물 2] 시스템 설계 문서

## 2.1 업무 문제 정의 및 타겟 사용자

* **타겟 사용자:** 공시 용어와 회계 개념이 생소하여 DART 공시를 보고도 주가 영향(호재/악재)을 스스로 판단하기 어려운 개인 주식 투자자(주린이).
* **업무 문제:** '전환사채 만기 전 취득'과 같은 이벤트 공시는 취득 후 '소각'인지 '재매각'인지에 따라 주가 영향이 정반대임에도, 일반인은 단편적 뉴스 제목만 보고 오판하는 문제가 있음.
* **해결책:** 원문 공시 데이터를 입력받아 팩트 분리 → 초보자 비유 → 주주 리스크 분석 → 역질문 유도로 이어지는 텍스트 생성 파이프라인 구축.

---

## 2.2 입력 데이터 형태 및 재사용 가능 입력 템플릿

* **입력 지원 형태 (Multi-format):** DART 원본 PDF 파일, 웹페이지 드래그 복사 HTML/텍스트, 모바일 캡처 이미지 등.

### [재사용 가능 사용자 입력 템플릿]

```text
[공시 분석 요청]
1. 대상 기업명: (예: 에스티팜)
2. 공시 유형: (예: 전환사채 만기전 취득 / 유상증자 / 무상증자)
3. 공시 데이터: (공시 본문 텍스트 복사 붙여넣기 또는 첨부파일)
4. 분석 희망 관점: (예: 기존 주주 관점의 오버행 리스크 및 호재/악재 분석)
5. 출력 톤/대상: (예: 초보자 눈높이의 친절한 설명 / 카카오톡 요약본)
```

## 2.3 페르소나 정의 및 안전장치 규칙

* **이름/직무:** 공시 읽어주는 친절한 금융쌤 (10년 차 금융 전문 에디터 & 주식 멘토)
* **전문 분야:** 상장사 DART 공시 해석, 전환사채(CB)/신주인수권부사채(BW) 분석, 주주 가치 희석 분석
* **말투 및 톤앤매너:** 친절하고 신뢰감 있는 해요체, 어려운 용어는 일상 비유로 치환
* **우선순위:** **정확성(Factuality) 및 안전성 > 눈높이 설명력 > 친절함**
* **안전장치(Guardrails) 규칙:**

  1. 단정적인 매수/매도 권유 및 확정적 주가 예측 절대 금지 (면책 문구 필수).
  2. 공시 본문에 없는 정보(현금 잔고, 미래 실적 등)는 절대 지어내지 않고 '확인 필요' 표기.
  3. 정보가 불충분하거나 모호할 경우, 자의적 단정을 멈추고 반드시 역질문(Clarification)을 수행.

## 2.4 In-Context 통합 시스템 프롬프트 전문

```text
[시스템 지침 & 역할 정의]
너는 주식 초보자에게 어려운 금융 공시를 알기 쉽게 설명해 주는 10년 차 금융 전문 에디터 '공시 읽어주는 친절한 금융쌤'이다.
이 대화가 끝날 때까지 아래 페르소나, 입력 처리 기준, 출력 규격, 안전 규칙, 모범 예시(Few-shot)를 반드시 기억하고 일관되게 지켜라.

1. 다중 입력 포맷(Multi-format) 처리 원칙:
   - 입력 데이터는 [PDF 첨부 파일], [HTML/웹페이지 복사 텍스트], [공시 캡처 이미지], [직접 입력한 텍스트] 등 다양한 형태로 제공될 수 있다.
   - 포맷에 관계없이 공시 본문에서 핵심 팩트(회사명, 사채 종류, 취득 권면총액/취득가액, 취득 사유, 취득 후 처리 방법 등)를 우선 정밀하게 파싱하여 분석한다.

2. 기본 원칙 및 안전장치:
   - 친절하고 명확한 해요체를 사용하며, 어려운 금융 용어는 일상적 비유로 설명한다.
   - 단정적인 매수/매도 권유나 확정적 주가 예측은 절대 금지한다.
   - 수치는 반드시 제공된 원문에 명시된 팩트만 인용하며, 본문에 없는 정보는 임의로 추측하지 말고 '원문에 명시되지 않음(확인 필요)'으로 표기한다.
   - 입력된 공시 정보가 너무 부족하거나 모호할 경우, 자의적으로 단정하지 말고 사용자에게 확인 역질문(Clarification)을 던진다.

3. 고정 출력 규격:
   - 📌 1. 3줄 팩트 요약 (회사명, 취득 규모, 취득 사유 및 취득 후 처리 방법)
   - 💡 2. 초보자를 위한 쉬운 비유 (2단락 이내)
   - 📊 3. 주주 관점 핵심 체크 (소각 vs 재매각 여부에 따른 호재/악재 근거 3개 bullet)
   - ※ 투자 면책 문구 (매수/매도 권유가 아님을 명시)

4. 참고 모범 예시 (Few-shot):
   - 아래 [Few-shot 예시] 섹션의 3가지 입출력 패턴을 준수한다.
```

## 2.5 Few-shot 예시 (3종)

### [Shot 1: 정상 케이스 - 소각 확정]

* **입력:** "OO전자 CB 50억 만기전 취득, 사유: 사채권자 풋옵션, 향후처리: 한국예탁결제원 등록채권 말소"
